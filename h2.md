  ## a) Metasploitable 2 -asennus Kali Linuxiin

Ensin latasin Metasploitable 2:n Rapid7:n verkkosivuilta, minkä jälkeen purin sen.

Siirrettiin purettu Metasploitable2-Linux -hakemisto VirtualBox VMs -hakemistoon.

Avattiin VirtualBox ja tehtiin uusi virtuaalikone. Asetin nimeksi Metasploitable.

Avattiin alavalikko Create a New Virtual Hard Disk, ja sen alta valittiin Use an Existing Virtual Hard Disk File. Tämän kohdalla klikattiin kansion kuvaa. Painettiin Lisää -kuvaketta vasemmassa yläkulmassa ja täältä avattiin Metasploitable2-Linux kansio, josta löytyi Metasploitable.vmdk -tiedosto. Avattiin se ja valittiin se.

Painettiin Viimeistele -painiketta.

Mentiin asetuksiin ja valittiin vasemmasta yläkulmasta Expert -asetukset. Vaihdettiin verkkoasetuksia siten, että liitettiin verkkosovitin kohteeseen Bridged Adapter NATin sijaan. Tämän jälkeen painettiin OK.

Kaiken tämän jälkeen Metasploitablea ei kuitenkaan saa käyntiin kunnolla. Käynnistäessä tulee vikailmoitus siitä ettei buutattavaa vaihtoehtoa löydy. Kokeilin vaihtaa asetuksista Levykuvien alta Metasploitable.vdk:n asetukset siten, että tsekkasin sen Solid-state Driveksi ja poistin tyhjän SATA 0 -portin (jossa olisi normaalisti jokin ISO-tiedosto).

Tämän jälkeen yritin uudestaan käynnistää koneen, mutta edelleenkin sama virheilmoitus tuli esille.

Seuraavaksi menin taas asetuksiin ja poistin UEFIn käytöstä. Tämä ratkaisi ongelman ja pääsin käynnistämään koneen normaalisti.

Kirjautuminen tapahtui tunnuksilla msfadmin:msfadmin

  ## b) Kalin ja Metasploitablen välinen virtuaaliverkko

Kalin ja Metasploitablen välinen virtuaaliverkko: Mennään VirtualBoxissa vasemmalla laidalla Verkko -> Host-only Networks (tämä on verkko, jossa virtuaalikoneet voivat kommunikoida vain keskenään) -> Create -> tämä luo verkon vboxnet0

Kalille verkko, jolla voi olla yhteydessä internettiin niin halutessaan: Verkko -> NAT Networks -> Create -> tämä luo verkon NatNetwork

Liitetään Metasploitable haluttuun Host-only verkkoon: Metasploitable -> Asetukset -> Verkko -> Sovitin 1 -> Liitetty kohteeseen -> Host-only Adapter -> Nimi -> vboxnet0

Liitetään Kalille Host-only verkko NATin rinnalle, jotta se voi kommunikoida Metasploitablen kanssa: Kali -> Asetukset -> Verkko -> Sovitin 2 -> Liitetty kohteeseen -> Host-only Adapter -> Nimi -> vboxnet0

Kalin Sovitin 1 on asetettu NATiin

  ## c) Testit
  
  Käynnistetään molemmat virtuaalikoneet.
  1) Suoritetaan pingaustesti: ping 8.8.8.8 -> Kalilla yhteys verkkoon kun molemmat verkkoadapterit on päällä, suljetaan verkkoadapteri 1 (NAT): Network is unreachable. Metasploitablella heti vastaus: Network is unreachable
  2) Tarkistetaan Metasploitablen ip-osoite komennolla ifconfig -> pingataan tätä Kalilla: on yhteys. Sama toisinpäin: on yhteys.

  ## e) Metasploitablen huolellinn porttiskannaus

nmap -A -T4 -p- [host]

Hyökkääjille kiinnostavimmat avoimet portit lienevät:
- 22: ssh, brute force hyökkäyksellä sisään ja tietojen varastaminen riskinä. vahvempi autentikointi apuun tähän
- 80: http, injektiohyökkäykset mahdollisia
